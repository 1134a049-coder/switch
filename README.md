# Switch《任天堂明星大亂鬥 特別版》單支 Joy-Con 新手教學網站

專為剛接觸 Switch《任天堂明星大亂鬥 特別版》（SSBU）的新手打造，主打 **單支橫握 Joy-Con** 即可快速上手的圖解教學、實機 GIF 示範、推薦角色速查與互動按鍵模擬器。

## 網站特色
- **開門見山玩法規則**：一進站立即看懂「% 數越高越飛」與「不會自動轉向」兩大核心觀念。
- **單支 Joy-Con 實體對照圖解**：完整標示搖桿、A 攻擊、B 必殺、SL 抓住、SR 防護罩與猛擊按法。
- **實機 GIF 操作示範**：內建原地平 A、B 必殺、蓄力猛擊、被擊飛回場、衝刺攻擊等實機操作畫面。
- **分頁切換＋大亂鬥風格底部進度條**：支援上下章節切換、即時位置指示與關鍵字搜尋。

## GitHub Pages 上傳部署方式
1. 在 GitHub 建立一個新的公開 Repository（例如 `ssbu-joycon-guide`）。
2. 將本資料夾內的所有檔案與子資料夾（`index.html`、`style.css`、`script.js`、`.nojekyll`、`README.md`、`GIF/`）直接拖曳上傳至該 Repository 根目錄並 Commit。
3. 前往 Repository 的 **Settings ➜ Pages**，在 **Build and deployment / Branch** 選擇 `main`（`/ (root)`）並儲存。
4. 等待約 1～2 分鐘，即可透過 `https://<你的帳號>.github.io/<Repository名稱>/` 瀏覽網站。
